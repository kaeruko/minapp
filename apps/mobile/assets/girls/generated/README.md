# MinApp Girls generated UI assets

These decorative assets are derived from the MinApp Girls visual direction approved for the login screen. The production login hero uses vector SVG artwork for deterministic Flutter rendering; the existing corrected mascot SVGs remain the canonical character artwork.

The login hero lace is intentionally drawn as part of the same cream/pink surface as the surrounding Girls screen. The lower lace continues into the page cream tone instead of appearing as a detached scalloped card border.
